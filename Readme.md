🎧 Spotify Listening Analysis – Power BI Dashboard

Understanding listening patterns is essential in today’s digital music world—for both users and streaming platforms.
This project analyzes Spotify listening data to uncover trends across Albums, Artists, and Tracks, helping identify how user engagement changes over time.

📌 Project Overview

This Power BI dashboard provides an end-to-end analysis of Spotify listening behavior.
It highlights yearly patterns, weekday vs weekend listening, top items, and year-over-year growth, enabling a deeper understanding of music consumption trends.

📂 Dashboard Sections & Key Insights
🎵 1. Albums Analysis
🔹 Total Albums Played Over Time

Track how album listening trends evolve monthly and yearly.

🔹 Number of Albums Listened by Year

Identify annual listening habits and volume.
(You can also find the minimum and maximum album count in the view.)

🔹 Weekday vs Weekend Analysis

Understand how album listening differs between weekdays and weekends.

🔹 Top 5 Albums

View the most frequently played albums.

🔹 Latest Year vs Previous Year Comparison

LY (Latest Year) vs PY (Previous Year) Trends

YoY (Year-over-Year) Growth Rate
